    • patchSettings(
          changes: Partial<WorkerSettings> & { bindings?: Binding[] },
      ): Promise<WorkerSettings>

      Changes some settings and keeps the rest.

      Bindings need care here: the API replaces the whole list, so a patch naming two bindings deletes every other one. patchBindings turns the rest into inherit entries, which is why this reads the current settings first.
